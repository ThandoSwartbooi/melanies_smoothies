🥤 Melanie's Smoothies
A Streamlit application built as part of the Snowflake Data Application Builders Workshop.

Overview
This application allows users to:

Create custom smoothie orders
Select up to 5 fruits
Retrieve fruit nutrition information
Store orders in Snowflake
Query data using Snowpark

How It Works
Fruit options are retrieved from Snowflake.
Users enter their name.
Users select ingredients.
Nutrition information is retrieved from an API.
Orders are stored in Snowflake.
